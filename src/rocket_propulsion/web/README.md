# Web interface

The browser client is intentionally framework-free. It renders the complete
engineering workbench and sends inputs to the Python JSON API; no engineering
equation is duplicated in JavaScript.

- `index.html` defines the app shell (top bar, grouped side navigation, one view
  per calculator) and the semantic forms and result grids. Form ids, field names,
  `data-key` result slots and chart ids are the contract with `app.js`.
- `styles.css` provides the responsive visual system. Every colour is a palette
  token (`--color-*`) from the vendored Sunumatik palette library, selected by
  `<html data-palette>`; type, spacing and radius follow a fixed budget
  (6 sizes, 2 button styles, 1 accent).
- `app.js` handles API requests, formatting, validation feedback and the SVG
  chart renderer (round Turkish ticks, palette series slots with dash patterns).
  `renderResults` writes only fields whose nearest `[data-module]` is the
  calculator that ran, so sibling workbenches keep their results.
- `shell.mjs` routes `#view` hashes, builds sub-calculator and chart tabs,
  restores the theme and last view, re-solves a form when a field changes and
  dims results while a request is in flight.
- `vendor/sunumatik/` holds the presets in use, generated by
  `scripts/sync_sunumatik_presets.py` (rule subsets of the stylesheets, a
  palette index, an icon subset, typefaces with their licences) and pinned by
  `PROVENANCE.json`.

The standalone Burn workbench resolves an engine operating point through
`/api/v1/engine-operating-point`, then sends the immutable point and burn
definition and optional piecewise-linear throttle schedule to
`/api/v1/burn/simulate`. It displays duration, impulse, ideal one-dimensional
delta-v, tank inventory, mass/thrust histories and closure evidence.
Canonical JSON, printable HTML, workspace persistence and optional Sidera
export all consume the returned artifact rather than recalculating results in
the browser. Variable profiles require the user to explicitly choose the
clearly labelled equivalent-constant approximation; exact mode fails closed.

The interface can later move to a component framework without touching domain
calculations or route contracts.
